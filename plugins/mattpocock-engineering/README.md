# mattpocock-engineering

Antigravity plugin packaging the `skills/engineering` folder of
[mattpocock/skills](https://github.com/mattpocock/skills) (MIT, see `LICENSE`).

Skills: ask-matt, code-review, codebase-design, diagnosing-bugs, domain-modeling,
grill-with-docs, implement, implement-spec, improve-codebase-architecture, pr,
prototype, research, retro, setup-matt-pocock-skills, tdd, to-spec, to-tickets,
triage, wayfinder, wizard.

Run `setup-matt-pocock-skills` once per repo before using the tracker-based flows.

Note: `grill-with-docs` delegates to the `grilling` skill from `skills/productivity`,
which is not included here.

To update: re-download the repo and replace `skills/` with `skills/engineering/*`.
